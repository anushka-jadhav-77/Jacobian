# 🤓 Jacobian Calculator

A beautiful Jacobian Matrix and Determinant Calculator built using Python, Streamlit, and SymPy.

## 🚀 Features

- 📐 Jacobian Matrix Calculation
- ✨ Determinant Solver
- 🧠 Answer Validation
- 📘 Step-by-Step Hints
- 🎨 Modern Glassmorphism UI
- 🌌 Animated Mathematical Background

---

## 🛠️ Technologies Used

- Python
- Streamlit
- SymPy
- HTML/CSS

---

## ▶️ Run Locally

Install requirements:

```bash
pip install streamlit sympy
```

Run Streamlit:

```bash
streamlit run app.py
```

---

## 📚 Sample Input

### Variables

```text
x,y
```

### Functions

```text
x+y
x-y
```

### Answer

```text
-2
```
